# stream-dlp 0.5.0

- Download native MP4 videos from public X and Twitter post links, including
  copied links with share parameters. X access is anonymous.
- Choose one video from a multi-video post, then choose its quality and save
  folder. Return to the entry list to save another video.
- X files use a source prefix and retain the original audio when present.
  Photo-only posts show a message explaining that a public video is required.
