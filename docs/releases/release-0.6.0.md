# stream-dlp 0.6.0

- Connect a separate session for YouTube, TikTok, or X by importing a cookie export for that platform. Firefox import and automatic refresh remain available for YouTube. Signed-in access to restricted TikTok and X posts is unverified.
- Download errors now identify the platform and explain what to do when a session expires, a site limits requests, or a video is unavailable or DRM-protected.
- Download logs show progress and processing events. Raw helper errors, signed links, and cookie values are excluded from those logs.
